## 二、22 个原视频的精炼内容（按知识点归并）

### 1. 正数与负数
- 温度计以零度为分界：比零大的叫正数，比零小的叫负数；正负 = 比零大/比零小。
- 负号长得像减号但念「负」；正号长得像加号但念「正」，实际应用中正号省略不写。
- 小学学过的数几乎都是正数，唯一例外是 0——0 是正负分界点，非正非负，没有符号。
- 正负数表示具有相反意义的量：体重增加 8 斤记 +8，减少 5 斤记 -5；向左 3 米记 -3 则向右 4 米记 +4（方向约定可互换，但相反意义的两个量一正一负）。
- 易错点：0 既不是正数也不是负数。

### 2. 有理数的概念
- 有理数 = 整数和分数的统称；本质 = 能写成两个整数之比的数。
- 有限小数（0.7=7/10、3.8=19/5）和循环小数（0.33…=1/3）都能写成分数，今后一律看作分数。
- 命名典故：徐光启把「可比」的「比」译成「理」，「可比数」遂成「有理数」。
- π 是无限不循环小数，不是有理数（高中证明）。
- 负数也是有理数：-1=-1/1、-6/5=-6/5、-0.7=-7/10。理解有理数千万别忘了负数。
- 注意三点：①有限/循环小数都看作分数；②无限不循环小数不是有理数；③别漏负数。

### 3. 有理数的分类
- 两把尺子：按「整数/分数」分，或按「符号正负」分；两种顺序结果都是五类：正整数、正分数、负整数、负分数、0。
- 整数按符号必分三类（正整数/负整数/0，0 非正非负单独一类）；分数只能分两类（正分数/负分数，分数没有 0）。
- 任何有理数不是整数就是分数，不会既是整数又是分数（4/2=2 是整数）。
- 例题集：-101/5、250、1/5、-2015、0、1.5、-0.111…、4/2。
- 「既不是整数也不是正数 → 负分数」的排除法解题示范。
- 新概念「非负数」：非负 = 不是负的 = 正或零 = ≥0；看到「非负」就翻译成大于等于零。

### 4. 数轴
- 温度计 → 数轴：规定原点、正方向（向右）、单位长度三要素的直线。
- 找分数位置：把单位长度平均分成若干份取几份；相反数关于原点对称。
- 点的移动问题：从原点向右 3 格再向左 5 格 → 3-5=-2；到 -1 距离 2 个单位长度的点有两个：1 和 -3（两种方向都成立，别丢答案）。
- 结论三点：三要素；点均匀分布、右正左负；移动问题画数轴、看起点方向步长。

### 5. 相反数
- 数轴上的点成双成对：1 和 -1、2 和 -2……数值相同、符号相反叫互为相反数。
- 几何意义：关于原点对称；0 的相反数还是 0。
- 代数表示：a 的相反数是 -a（负号表示「相反」）；-(-5)=5 即负负得正；-(+2)=-2（正号可省略）。
- 注意三点：关于原点对称（0 的相反数是 0）；求相反数统一添负号；正号可省、双负号抵消。

### 6. 绝对值
- 汪星人故事：从原点出发走 3 个单位长度，向左到 -3、向右到 3，方向不同但到原点的距离都是 3。
- 定义：数轴上表示数 a 的点到原点的距离叫做 a 的绝对值，记 |a|。
- 法则：正数的绝对值是它本身；负数的绝对值是它的相反数；0 的绝对值是 0。
- 任意数 a 分三种情况：a>0 时 |a|=a；a=0 时 |a|=0；a<0 时 |a|=-a。先判断符号再求值。
- 反问题：|a|=3 → a=±3；|a|=a → a≥0 即 a 是非负数。

### 7. 绝对值非负性
- 任意数的绝对值都 ≥0（正数本身、负数变相反数、零还是零）。
- 用途一：求最小值——|x| 最小值是 0（x=0 时取得）。
- 用途二：|x|+|y|=0 → 两个非负数相加和为零，只能都是 0 → x=0,y=0。
- 升级：|x-2|+|y-3|=0 → x-2=0 且 y-3=0 → x=2,y=3（把 x-2 看整体，整体非负）。
- 口诀：非负 + 非负 = 0 ⇒ 每一个都是 0。

### 8. 有理数比较大小
- 方法：都摆到数轴上，从左往右就是从小到大（左小右大）。
- 例题：-1/3、0、-1、0.5、-1.4 排序；-1.7 到 3.2 之间有 5 个整数（-1,0,1,2,3）。
- 易错点：负数之间数值越大数反而越小（-5 < -1），和小学正数经验相反，强调两遍。

### 9. 有理数的加法
- 加法法则用正数国/负数国火拼故事讲：同号相加能量累加、符号不变；异号相加能量抵消、符号跟能量值高的、数值取差。
- 例题：3+4=7、5+6=11；-3+(-4)=-7；4+(-3)=1；9+(-6)=3；(-4)+3=-1；2+(-7)=-5；4+(-4)=0。
- 相反数相加和为零：-3+3=0、-a+a=0。
- 总结：同号累加符号不变；异号抵消符号跟大的；互为相反数则和为零。

### 10. 有理数凑整巧算
- 招式一：同分母分数先凑。(-2又1/3)+(-3又2/3)=-6；整数部分相加、同分母分数凑整再合并。
- 招式二：交换位置凑（带符号搬家）：把好算的换到前面先算，-3又2/3 换前面与 2又1/3 凑成 -6，再加 6.3 得 0.3。
- 招式三：先把减法变加法，再用交换律结合律（-7/6 减 -6/7 变加 6/7 等）。
- 易错点：负数「裸奔」要加括号；换位置必须带符号。

### 11. 相反意义的量与有理数加减
- 警察南北大道巡逻：规定向北为正，记录一天行驶，求最终位置 = 所有数带符号相加（27+(-41)=-14，岗亭南边 14 千米）。
- 求总路程 = 不管符号把所有数值相加（=68 千米）；每千米耗油 a 升则总耗油 68a。
- 易错点：总路程 ≠ 位移，-14 千米是位置不是路程，不能拿 14×a。

### 12. 减法及加减法混合运算
- 减法转加法：减去一个数 = 加上它的相反数。4-3=4+(-3)；a-b=a+(-b)。
- 形象讲法：把减号当作负号给后面那个数，中间挤一个加号。
- 例题：5-7=-2；-6-8=-14；-3-(-4)=1；4-(-3)=4+3；5-(-6)=5+6；-7-(-5)=-7+5。
- 加减混合：先把所有减法变加法再按顺序算：-5-3+7+2 → -5+(-3)+7+2=1。
- 带绝对值版本：先去绝对值（|-2|=2）再减法变加法；曲线括号 vs 直线绝对值别搞混。
- 总结：减法法则（减变加相反数）；混合先统一成加法；括号和绝对值分清。

### 13. 有理数的加减混合运算
- 三步口诀：有加有减先把减变加；能凑整就凑整；整数分数分组算。
- 例题一：-1/3 与 -2/3 凑 -1，两组负数凑整求和。
- 例题二：整数一组（同号累加得 -20），分数一组通分（12/10+(-7/10)=5/10=1/2），合起来 -19又1/2。

### 14. 有理数的乘法
- 推导路径：负号提出来先算数值再放回 → 一正一负为负；两负相乘「向后转」比喻 = 负负得正。
- 任何数乘 0 都得 0。
- 法则：同号得正、异号得负、任何数乘 0 得 0。
- 多个数相乘：数负号个数，奇数个负号结果为负、偶数个得正 = 奇负偶正（奇偶指负因数个数，与正因数个数无关）。
- 例题：四个负因数一串连乘，先定正号再约分：4 与 4 约、2×3=6，得 7/6。

### 15. 利用乘法分配律巧算
- 分配律 a(b+c)=ab+ac 正用：括号里每项都带符号与外面相乘（2 + (-2/3) + 1/5 脑补加号）。
- 例题一：-15×(2 - 2/3 + 1/5) = -30+10-3=-23。
- 除法版：先除变乘（除以 -42 变乘 -42）再分配。
- 倒用 = 提取公因数：-5/14×(7+9-2)=-5/14×14=-5；公因数符号不统一先统一（1/3 改成 -(-1/3)，加号改减号）。
- 总结：正用带符号；遇除变乘；倒用找公因数、先统一符号。

### 16. 除法及乘除混合运算
- 法则：除以一个数 = 乘它的倒数；求倒数保留符号、分子分母交换；0 没有倒数。
- 倒数推导示例：-5/2 乘谁等于 1？因为 5/2×2/5=1，且负负得正，所以 (-5/2)×(-2/5)=1，故 -5/2 的倒数是 -2/5（保留符号、交换分子分母）。
- 例题：3÷(-2/5)=3×(-5/2)=-15/2。
- 乘除混合必须从左到右；先把除法全变乘法再约分；小数先化分数（5.9=59/10）。
- 例题：-14×7/9÷20×5.9 类连乘约分（20 与 14 约 2、59 与 7 等）。
- 提醒两点：除法全变乘法防约错；小数化分数便约分。

### 17. 复杂的乘法运算
- 错误示范先行：中间挑好算的约（-1÷-1=1）是标准错误——乘除混合必须先把除变乘再算。
- 正例：÷(-1/3) 变 ×(-3)，两负得正，约分得 9。
- 带绝对值的乘除：先算绝对值（|3/4-1|=1/4），带分数化假分数（2又1/4=9/4），除变乘后约分得 -2。
- 口诀：遇绝对值先算绝对值；除变乘再约分。

### 18. 有理数的四则混合运算
- 顺序与小学相同：先括号、再乘除、后加减。
- 例题：5-3÷(-1/2)+(-2)×1/4 → 3÷(-1/2)=-6；(-2)×1/4=-1/2 → 5-(-6)+(-1/2)=10.5=21/2。
- 负数不能裸奔：-6、-1/2 参与加减必须加括号。
- 加括号版：先算括号里的乘除再加减。
- 带绝对值版：|96| 先求；(-2/5)×(3/5)=-6/25，÷(-6/25) 变 ×(-25/6) 约掉得 -25。
- 练习二：乘除必须先除变乘再约（4 与分母 2 约、3×3=9，得 3-9=-6）。

### 19. 有理数的乘方
- 从面积/体积引入：a² = 两个 a 相乘（二次方），a³ = 三个 a 相乘（三次方），aⁿ = n 个 a 相乘。
- 命名：a 叫底数、n 叫指数（像手指举在上面）、整个算式叫乘方、结果叫幂；读作 a 的 n 次幂。「幂」不叫「乘方」的明星段子：那个明星可不叫杨乘方。
- 指数管辖范围（本课最重要）：没括号指数只管紧挨的数；有括号指数管整个括号。
  - -5² = -(5×5) = -25（指数只管 5）
  - (-5)² = 25（指数管整个 -5）
  - (-2/5)² = 4/25（符号参与）
  - (2/5)² 分子分母各自平方 = 4/25
  - -(2/5)² = -4/25（负号在括号外不参与）
  - -4/(5²) = -4/25
  - (-2/5)² 与 -2²/5² = -4/25 的对比
- 底数可以是任意有理数。

### 20. 有理数的混合运算
- 顺序：先乘方、后乘除、再加减；有括号先算括号。
- 例题：(-2)⁴÷16×3+(-7)-(-1) → (-2)⁴=16 → 16÷16×3=3 → 3+(-7)-(-1)=-3。
- 注意点一：(-1) 的奇次方 = -1、偶次方 = 1（奇负偶正）。(-1)^2014=1、(-1)^2015=-1 → 1-(-1)=2。
- 注意点二：指数管辖范围（符号/分子/分母谁参加乘方），五连辨析题。

### 21. 科学记数与近似数
- 规律：10、100、1000、10000…后面几个零就是 10 的几次方。
- 科学记数法：a×10ⁿ，其中 1≤|a|<1 的整数部分必须是一个大于零的一位数（a 的整数部分一位且非零）。
- 6000=6×10³（不写 60×10² 或 0.6×10⁴）；2015=2.015×10³；2015.6=2.0156×10⁴；-307196.33=-3.0719633×10⁵。
- 技巧：10 的指数 = 小数点移动的位数。
- 近似数：四舍五入；精确到千位时看原来那个数的千位（-3.07×10⁵ 精确到千位）。
- 提醒：精确到十位百位要回原数找对应数位。

### 22. 有理数概念综合
- 快问快答五连：
  1. 谁的相反数等于它本身？→ 只有 0
  2. 谁的绝对值等于它本身？→ 正数和 0（非负数）
  3. 谁的倒数等于它本身？→ 1 和 -1（别漏 -1）
  4. 谁的平方等于它本身？→ 1 和 0（-1 的平方是 1 不是本身）
  5. 谁的立方等于它本身？→ 0、1、-1
- 记忆法：记不住就把 0、1、-1 依次代入验证。
- 没有最小的整数（负数可以无限小）；最小的正整数是 1；最大的负整数是 -1；绝对值最小的数是 0。
- 综合题心法：多想想 0、±1 和数轴。
