基于两张参考图的风格解码，为「人机协同助学智能体」学生端设计两套差异鲜明、可落地实现的完整 UI 方案，并给出学生端与教师端在信息架构与功能入口上的具体调整对比。

0 · 设计输入：两张参考图的风格解码

参考图一 · 个人作品集（Vanger Chan）

  • 版式：编辑排版（Editorial）——巨型衬线标题 + 斜体强调词，左右不对称双栏（文字 / 手绘插画）
  • 色彩：暖纸米色底、墨黑文字、一点朱砂红作强调
  • 质感：报纸 / 杂志 / 手账感，虚线分隔、小型大写字母标签、细边框
  • 气质关键词：人文、手工、个人化、阅读感强

参考图二 · 博客「面试手记」

  • 版式：现代卡片（Warm Card）——圆角卡片、徽章标签（新企划·即将上线）、列表行 + 箭头 Chevron
  • 色彩：暖白纸底、纯白卡片、低饱和状态色
  • 质感：轻盈、清晰、工具化，信息密度高但有呼吸感
  • 气质关键词：清晰、轻量、高效、日课式陪伴
两套方案分别承接这两种气质：方案一「墨读」把学生端做成一本会更新的学习学报；方案二「云课笺」把学生端做成一张温暖的学习工作台。两者在字体、色彩、形状、插画、信息密度上全面区分，可独立选用，也可作为「双皮肤」共存（见第 5 节）。

1 · 方案一「墨读」——学报 / 编辑排版风

1.1 设计理念

把学生端做成一本「会更新的学习学报」：每一次预习是「读者来信」，每一道练习题是「今日专栏」，每一次 AI 反馈是「红批」，每一场模拟面试是一封「面试函」。用编辑排版的语法重新组织学习界面，让工具退后、让内容上前。

  • 阅读优先：弱化控件装饰，用衬线大字、分栏、留白建立信息层级，界面像一页可以静心读下去的报纸
  • 人文温度：手绘线稿插画、纸感底色、墨色细边框，消解在线考试系统的紧张感与距离感
  • 仪式感运营：栏目化（COLUMN / LETTER / 日课）赋予重复行为以期待感，支撑「人人参与」的练习文化

1.2 适用场景

  • 重内容、重阅读、重表达的页面：AI 答疑、一人一题、案例研讨、考核作答
  • 对外展示与答辩演示：第一眼辨识度极高，「课程即刊物」的概念易于讲述，适合竞赛路演与课程宣传
  • 人文气质课程（管理学、经济学等经管类）：与学科气质同构
  • 局限：高密度数据管理页（学情统计、复核台）不是其强项，此类页面建议沿用中性后台风格

2 · 方案二「云课笺」——暖纸卡片 / 现代极简风

2.1 设计理念

把学生端做成一张「温暖的学习工作台」：一屏一个任务，一张卡片一件事。用参考图二的语汇——徽章标签、圆角卡片、日期前缀列表、Chevron 引导——把五大学生功能（待办、练习、案例、考核、答疑）组织成清晰、可预期、低学习成本的日常流程。

  • 信息卡片化：每张卡片只回答一个问题（做什么 / 怎么样 / 下一步），卡片即操作单元
  • 状态可见：徽章（第 8 周·进行中）、进度环、倒计时、状态点，让学习进度与待办一目了然
  • 操作直达：列表行右侧 Chevron + 主按钮，任何页面两步内到达核心功能

2.2 适用场景

  • 功能型页面：一人一题、案例提交、考核作答、作业管理——流程长、状态多，卡片式最稳
  • 高频日常使用：学生每天进入先看「今日待办」，卡片流的浏览效率最高
  • 信息密度高的场景：班级数据、练习记录、题目列表，网格与列表混排从容
  • 局限：辨识度与「惊艳感」弱于方案一，视觉同质化风险需靠细节（暖纸色、手绘小图标、空状态插画）化解

4 · 学生端与教师端：信息架构与入口调整对比

学生端与教师端保持核心功能入口不变（一人一题、课前案例、课程考核、AI 答疑、论坛、作业六大功能双向保留），但按角色重组入口位置与信息展示：学生端围绕「学习动线」，教师端围绕「治理动线」。

4.2 同一信息的学生端 / 教师端呈现差异

信息学生端呈现教师端呈现
学习进度个人章节完成度 + 连续学习天数班级平均进度 + 分布直方图
案例我的投稿状态（待选用 / 已选用 / 已驳回）案例池统计（按章节 / 学科 / 提交时间）
练习数据我的最近三次反馈 + 章节覆盖班级练习人次、章节分布、零练习预警名单
考核我的题目、作答、AI 反馈、得分待复核计数、已答率、分数分布、评分入口
答疑我的对话历史高频问题 TopN + 知识点缺口提示
三条调整原则：① 动线原则——学生端按「预习 → 练习 → 作业 → 考核」的教学周排序，教师端按「待处理数量」排序；② 视角原则——同一功能，学生看「我的」、教师看「班级的」（案例：投稿箱 / 选稿台；考核：答题卡 / 阅卷台）；③ 减负原则——学生端不放任何管理操作与班级数据，教师端不放置障的答题入口，配置类收入「设置 / 我的」。

5 · 落地建议

5.1 组件映射（两套主题均可落地）

设计元素方案一「墨读」方案二「云课笺」
主题实现Element Plus CSS 变量覆写 + 衬线字体栈；Vant ConfigProvider 主题Element Plus / Vant 默认卡片规范微调（圆角 / 阴影 / 暖底色）
大标题自定义 SerifTitle 组件（斜体强调词插槽）标准标题 + 徽章行
题卡 / 任务卡报纸剪贴卡片（骑缝标签 + 衬线排印）标准圆角卡 + 状态徽章
AI 反馈红批批注框（朱砂虚线 + 批注语气）三维度评分小卡（评分条）
插画手绘 SVG 线稿（约 6–8 幅，可复用）线性小图标 + 空状态插画
预估工时约 5–7 人日（主题 + 插画 + 定制组件）约 2–3 人日（主题变量 + 卡片规整）

5.2 推荐路径

  • 推荐「双皮肤」方案：以方案二「云课笺」为默认皮肤（成本低、功能全、适合日常高频使用），将方案一「墨读」制作为「阅读模式 / 主题皮肤」——在答疑、一人一题、考核等重阅读页面可一键切换，兼顾日常效率与答辩演示的辨识度。
  • 两套皮肤共用同一套信息架构（第 4 节）与组件接口，仅更换 design token（色彩 / 字体 / 圆角 / 阴影）与插画资源，切换不影响功能与数据。
  • 若只能选一套：面向竞赛答辩与课程宣传选「墨读」；面向真实教学使用与迭代选「云课笺」。
