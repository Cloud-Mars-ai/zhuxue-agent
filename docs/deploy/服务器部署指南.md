# 服务器部署指南（zhuxue-agent 后端）

> 部署时间：2026-11-07 · 部署人：WorkBuddy · 服务器：152.136.121.153（OpenCloudOS 9.6 / 腾讯云）

## 1. 架构说明

本项目"后端"是**单个 Node 进程**（`frontend/server.mjs`），零 npm 依赖（仅 Node 内置模块），同进程承担两个职责：

| 职责 | 路径 | 说明 |
|---|---|---|
| 静态托管 | 其余所有路径 | 服务 `dist/` 构建产物；相对 base 深链接修正（`/m/course` → `/assets/...`）；未命中回退 `index.html` |
| AI 代理 API | `/api/ai/chat` | 转发 DeepSeek 对话（`DEEPSEEK_API_KEY`） |
| AI 代理 API | `/api/ai/tts` | 转发 StepFun 语音合成（`STEPFUN_API_KEY`，可选） |
| 健康检查 | `/api/health` | 返回 key 配置状态 |

未配置 API Key 时 AI 功能自动降级为前端演示缓存（项目硬规则 6）。

## 2. 部署形态

```
/home/wppjkw/zhuxue-agent/
├── server.mjs      # 主服务（从 frontend/server.mjs 同步）
├── aiProxy.mjs     # AI 代理逻辑
├── package.json    # 仅 { type: module }
├── dist/           # Vite 构建产物（npm run build）
└── .env            # PORT=4173；API Key 可选
```

- **进程管理**：pm2，进程名 `zhuxue-agent`，端口 **4173**
- **保活**：`pm2 save` + 用户 crontab `@reboot pm2 resurrect`（服务器无 sudo，不用 systemd）
- **访问地址（内网验证过）**：`http://127.0.0.1:4173`（health/index/深链接/静态资源全部 200）

## 3. 外网访问：反代已配好，只差一条 DNS 记录

服务器 80/443 是宝塔 nginx（**该服务器 wppjkw 用户有完整 sudo 权限**，iptables 确认本机无封锁；
未放行的是云厂商安全组，且服务器不在本人的腾讯云 CVM 账号下，控制台改不了——已绕开）。

已在 nginx 新增 vhost `/www/server/panel/vhost/nginx/zhuxue.wppjkw.online.conf`（只新增、未动任何现有站点）：

```
server_name zhuxue.wppjkw.online;  →  proxy_pass http://127.0.0.1:4173
```

服务器本地已全量验证（Host 头模拟）：`/`、`/m/course`、`/app/course`、`/favicon.svg`、静态资源、SPA 回退、`/api/health` 全部 200；`api.wppjkw.online`、默认站不受影响。

**唯一剩余步骤（需用户操作，约 2 分钟）**：域名 `wppjkw.online` 的 DNS 在 **DNSPod**（注意：DNSPod 与腾讯云 CVM 控制台是两套账号，CVM 里看不到资源不代表 DNSPod 里没有）：

1. 登录 [console.dnspod.cn](https://console.dnspod.cn)（微信/QQ）
2. 选择域名 `wppjkw.online` → 记录管理 → **添加记录**：
   - 主机记录：`zhuxue` ｜ 类型：`A` ｜ 记录值：`152.136.121.153` ｜ TTL：600
3. 保存后等待 1–10 分钟生效，访问 **http://zhuxue.wppjkw.online**

生效后如需 **HTTPS**（推荐，正式演示用）：在 DNSPod「密钥管理」创建 API ID/Key 发给维护人，用 acme.sh DNS 验证签发证书并自动续期，再补 443 server 块 + 301 跳转（模板照抄 `api.wppjkw.online.conf`）。

## 5. 配置真实 AI 能力（可选）

编辑服务器 `~/zhuxue-agent/.env`，填入密钥后 `pm2 restart zhuxue-agent`：


验证：`curl http://127.0.0.1:4173/api/health` 应返回 `textModelConfigured: true`。

> 安全提示：API Key 只放服务器 .env，不要再写进前端源码（AGENTS.md 硬规则；旧 key 已泄露需轮换）。
