# 发布证据：DeepSeek 与课程生成体验升级

日期：2026-11-04

## 变更

- 默认文本模型切换为 DeepSeek `deepseek-chat`，保留模型设置页手动切换能力。
- 课程场景生成由串行改为最多 3 路受控并发，单场景完成即写入 IndexedDB。
- 课程生成入口迁移到首页教师输入区，直接使用已上传教师材料生成可编辑大纲。
- 学生 Web/H5 首页也已开放同一套课程生成入口与个人课程编排。
- 首页模式选择改为“浅色提示 → 选择后收成左下角校园图标”，可从图标重新切换。
- 板书增加语音教学开关、5 个 StepAudio 中文音色、自动跟读字幕与下一段语音预取。
- 板书增加自包含 HTML 下载。
- 生成确认后进入独立的全屏课程体验页，带轻阴影展示框和横向滚动场景轨。
- 第一完成场景立即可体验，其余场景在后台继续生成并实时补齐。
- 落地页增加全屏欢迎动画：完整播放一次后循环招手段，点击后进入现有落地主页。
- 本地/生产静态服务器补充 HTTP Range（206）支持，保证视频循环与拖动稳定。

## 验证

- `npm run build`：通过
- `npm run test:e2e`：20/20 通过
- `npm run test:e2e:live`：5/5 通过
  - DeepSeek 普通回答
  - StepAudio 3 TTS
  - 板书语音跟随字幕自动播报
  - DeepSeek 结构化板书
  - DeepSeek 课程大纲与首个场景
- DeepSeek JSON mode：HTTP 200，返回合法 JSON
- StepAudio 音色实测：`qinhenvsheng`、`linjiajiejie`、`cixingnansheng` 均返回 `audio/mpeg`
- 首页真实建课实测：7.9 秒生成大纲，17.6 秒完成 6 个场景的资源包（3 路并发）

## 风险

- DeepSeek 与 StepAudio 密钥仍会进入前端公开构建，正式发布前需要迁移后端代理并轮换。
- 语音自动播报依赖浏览器允许音频播放；被浏览器拦截时会显示提示并继续字幕播放。
