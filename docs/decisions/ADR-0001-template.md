## 示例：ADR-0002 课程材料与轨迹使用 IndexedDB

- **状态**：已采纳
- **背景**：一学期课件文本与学习轨迹会超过 localStorage 5–10MB 上限，且同步写入会阻塞主线程。
- **决策**：材料、切片、轨迹存 IndexedDB；localStorage 只保留配置与轻量画像。
- **替代方案**：localStorage（容量不足）、后端优先（后端未就绪）。
- **代价**：读取变为异步，所有消费方需处理加载态；迁移期需双写。
- **推翻条件**：后端提供材料与轨迹接口后，IndexedDB 退化为离线缓存。
- **回滚点**：`repositories/db.js` 保留 localStorage 适配器，开关 `flags.knowledgeBase` 可关闭。
