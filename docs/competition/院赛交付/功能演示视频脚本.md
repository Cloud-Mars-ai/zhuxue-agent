# 院赛功能演示视频脚本

状态：待团队录制
建议成片：4 分 30 秒左右，MP4。此脚本不是已完成的视频；当前仓库中的《智慧学伴演示视频》属于另一项比赛。

## 录制前

- 使用本地生产构建，准备 `student` 和 `teacher` 两个演示账号。
- 清空真实姓名、个人数据和浏览器通知；只展示仿真课程数据。
- 关闭含个人信息的桌面通知；确认页面标有“模拟数据/演示缓存”。
- 若录入 AI 密钥，使用受控服务端配置，录屏不展示控制台、环境变量或密钥。
- 按实际通知群要求确认视频分辨率、命名、时长和提交渠道。

## 镜头脚本

| 时间 | 画面与操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:20 | 落地页，指出《管理学》课程与独立的智慧学伴入口 | 本作品服务经管课程教学场景，选择智能体赛道；当前展示数据为仿真数据 |
| 0:20–0:55 | 学生进入课程首页，打开章节自测 | 先测后学；学生独立作答后查看解释，不把答案前置 |
| 0:55–1:35 | 进入一人一题，生成题目并提交示范回答 | 题目结合章节/学科背景，反馈落到观点、理论和表达，不声称真实学习提升 |
| 1:35–2:05 | 查看课程材料或结构化板书 | 讲解以结构化内容呈现；引用材料须能由课程资料回查 |
| 2:05–2:35 | 学生提交案例并切换教师账号 | AI 整理摘要，是否采用由教师决定 |
| 2:35–3:25 | 教师查看案例、进入考核复核，编辑或驳回后再发布 | 教师保留复核与发布权，AI 草稿不自动成为正式考核内容 |
| 3:25–4:05 | 学生查看任务并提交，教师查看学习分析 | 分析来自演示数据，指出统计和建议边界 |
| 4:05–4:30 | 回落地页或收束页，展示本地访问方式 | 说明仿真数据、无真实成效结论，并给出已验证的访问方式 |

## 录制验收

- 全程不超过 5 分钟；画面可读、鼠标操作清楚、讲解与操作同步。
- 覆盖学生和教师两种动线，并至少展示一次“学生作答—教师复核”闭环。
- 不将模拟人数、示例成绩或模型生成内容说成真实运行结果。
- 成片需由团队完整回放一次，检查静音、错页、账号信息和个人信息泄露。
