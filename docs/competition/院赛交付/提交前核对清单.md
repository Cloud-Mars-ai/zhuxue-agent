# 院赛提交前核对清单

依据《关于举办2026年“人工智能+管理”院级竞赛的通知》及项目当前代码。竞赛通知群后续发布的要求优先补充本表。

## 规则硬项

- [ ] 队伍为 3–5 名学生，每名学生只参加一队。
- [ ] 至少 1 名队员为北京化工大学经济管理学院在籍学生。
- [ ] 指导教师不超过 2 人。
- [ ] 选报一个赛道；本项目拟报“智能体”。
- [ ] 提交可运行系统、项目说明书、功能演示视频、部署/访问说明和测试账号。
- [ ] 说明书写明服务课程、授课对象、教学目标、教学环节、拟解决问题、使用流程和预期作用。
- [ ] 开源框架、第三方模型、课程资源和生成式 AI 工具注明来源、使用范围及二次开发内容。

## 项目当前待办

- [ ] 填写并核验队伍名称、成员、学院身份、分工和指导教师。
- [ ] 由课程负责人确认课程范围、教学目标、真实痛点依据及课程资源使用授权。
- [ ] 按最终要求导出并复核说明书 PDF 或指定格式。
- [ ] 录制并完整回放院赛专用功能视频；智慧学伴视频不可替代。
- [ ] 选定托管方式并实测最终访问地址、Web/H5、深链接和账号。
- [ ] 按实际构建依赖复核许可证和第三方素材；更新 `THIRD_PARTY_NOTICES.md`。
- [ ] 负责人轮换曾公开泄露的 API 密钥；确认仓库、构建产物和视频中均无新密钥。
- [ ] 检查是否有后续通知、提交截止时间、命名规范和额外模板。

## 不可宣称事项

- 当前没有证据证明《管理学》作品已在真实课程运行。
- 当前没有经对照或独立评估验证的学习成效数据。
- 前端内置账号为公开仿真账号，不具备生产环境安全性。
- 智慧学伴公开模拟数据和交付包仅属于对应赛题，不是经管课程数据。
