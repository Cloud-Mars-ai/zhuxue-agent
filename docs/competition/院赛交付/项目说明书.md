## 一、作品概述

本作品面向经管课程中的课前预习、案例研讨、课堂练习、课后巩固、学习评价和教师备课，提供角色化的人机协同助学流程。它将对话入口、课程资料检索、练习反馈、案例整理、考核复核、学情查看和结构化课程讲解组织在同一应用中。

AI承担解释、练习生成、反馈表达和课程内容组织等辅助工作；学生作答、教师审阅与调整仍是教学流程的一部分。当前为前端演示系统：账号、课程活动及学习记录为本地仿真数据，不能用于真实身份认证、正式成绩管理或跨设备协作。

## 二、服务课程与对象

- 当前课程模型：6 个章节，涵盖管理基础、管理理论、决策与计划、组织、领导与激励、控制。

## 三、教学目标与拟解决问题

### 设计目标

1. 为学生提供可随时进入的章节练习与具体反馈，增加主动检索和表达观点的练习机会。
2. 用案例征集和课程资料入口为课前预习、课堂讨论准备可用素材。
3. 将练习过程中的薄弱点连接到后续复习、练习和模拟考核，帮助学生理解下一步行动。
4. 为教师提供案例筛选、题目复核、过程性表现查看和课程内容组织工具，保留教师判断与调整环节。

以上是产品设计目标，不是已测得的学习增益或教学效果。真实效果需经教师和学生试用、基线比较及合规审批后评估。

### 拟回应的教学问题

- 大班课堂中，学生获得口头练习和即时反馈的机会有限；
- 学生课前不易把抽象理论联系到身边案例；
- 练习、课程评价与后续复习之间缺少连贯的个性化提示；
- 教师需要在备课、案例筛选和题目复核上投入较多重复劳动。

这些问题是产品设计所针对的场景假设；**[请课程团队确认其与实际课程痛点及访谈依据一致]**。

## 四、教学环节与使用流程

### 学生流程

1. 登录后进入课程首页，选择章节自测、资料学习、直接提问或案例提交。
2. 通过章节与题型生成练习，独立作答后查看观点结构、理论运用和表达逻辑等反馈。
3. 根据学习体检、错题和课程材料继续练习；需要时使用结构化板书课程学习。
4. 对教师发布的模拟考核作答，并查看反馈。

### 教师与助教流程

1. 查看课程资料和待处理活动；教师可维护资料，助教按授权协助处理。
2. 筛选学生提交的案例，决定是否用于课堂研讨。
3. 设置考核范围，查看并编辑 AI 草拟题目，审核后发布。
4. 查看过程性学习摘要与知识点分析，为教学安排提供参考。

### 教师控制边界

AI 生成内容用于辅助而非自动定稿。考核发布、案例采用和教学决策由教师确认。对于统计呈现，必须区分模拟数据与真实观察；当前项目没有真实课堂成效数据。

## 五、功能与特色

| 功能 | 面向用户 | 教学用途 |
| --- | --- | --- |
| 对话式学习入口 | 学生、教师 | 理解意图并导航到课程工具 |
| 课程资料与检索 | 教师维护、学生使用 | 让问答和课程讲解围绕指定课程材料 |
| 章节自测与一人一题 | 学生 | 先测后学、独立作答、获得可执行反馈 |
| 案例征集与教师选用 | 学生、教师 | 将课外观察带入课堂研讨 |
| 个性化模拟考核 | 教师、学生 | 教师圈定范围、复核题目，学生作答并查看反馈 |
| 学习体检与课程编排 | 学生、教师 | 连接学习状态、下一步行动和结构化讲解 |
| 结构化板书 | 学生、教师 | 按内容区块逐步讲解、追问和复习，不使用自由画布 |

产品特点是把练习、反馈、教师复核与课程讲解串成教学工作流，而非只提供开放式聊天。课程工作流与七年级数学智慧学伴数据域分开；两个比赛场景仅共享应用框架和导航，不共享学生记录或分析结果。

## 六、技术方案与运行方式

- 前端：Vue 3、Vite、Pinia；桌面界面使用 Element Plus，移动 H5 使用 Vant。
- 数据：当前演示账号、课程活动及多数学习状态保存在浏览器本地；数学赛事另有独立数据模块。
- AI：服务器端代理可选接入 OpenAI 兼容文本服务及 StepFun 语音服务；未配置服务端密钥时，支持本地确定性演示兜底并标注“演示缓存”。
- 教学规则：重要数据统计、业务映射和结构化板书由前端受控逻辑处理；模型输出不能代替教师审核。
- 详细运行要求见本目录《部署与测试账号说明》。

## 七、预期作用与验证计划

预期作用包括提高学生练习和反馈的可达性、帮助学生形成下一步学习行动，并减少教师整理案例和逐题检查的重复操作。上述作用尚未通过真实课程对照、用户研究或学习成效评估验证。

建议后续由课程团队确认后开展小范围试用，并记录：任务完成率、学生反馈、教师复核时间、错误/不适用建议比例，以及课程前后测或其他经审批的学习指标。试点前须取得必要授权、完成隐私评估并避免将真实学生信息送入未批准的模型服务。

## 八、数据、隐私与安全

- 当前交付演示采用仿真课程活动和本地演示账号，不应录入真实学生姓名、学号、成绩或敏感信息。
- 演示账号密码为公开固定值，仅供本地展示，不具备生产环境安全性。
- 模型密钥应仅保存在受控服务端环境变量；历史公开提交中曾存在明文凭据，相关密钥轮换仍须负责人在服务商控制台完成。源码当前不应新增密钥。
- 真实部署前需要后端身份认证、角色授权、日志和数据保留策略；当前纯前端角色控制不构成安全边界。
