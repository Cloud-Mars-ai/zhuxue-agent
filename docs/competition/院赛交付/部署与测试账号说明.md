# 部署与测试账号说明

适用作品：人机协同助学智能体（院赛智能体赛道）
核验范围：仓库中的本地前端演示配置；不是公网可用性声明。

## 本地运行

环境为 Node.js 22 或兼容 Vite 8 的受支持版本。Windows PowerShell：

```powershell
cd frontend
npm install
npm start
```

`npm start` 会先生成相对路径构建产物，再由项目自带的 Node 服务在 `http://localhost:4173` 提供应用。深链接应通过该服务验证，不要用纯静态文件服务器替代。首次安装依赖时如仓库已有 `node_modules` 可跳过 `npm install`。

无网络或未配置 AI 服务时，确定性演示功能使用本地仿真内容。联网 AI 与语音功能需在受控服务端配置密钥；不要把密钥填进前端、截图、说明书或 GitHub。

## 测试建议

1. 以 `student` 登录，走章节自测或一人一题，并确认提交前不显示解析。
2. 以 `teacher` 登录，检查案例筛选与考核题目复核流程。
3. 分别在 Web 和 H5 查看同一课程的角色界面与窄屏布局。
4. 清除浏览器本地存储后重试，确认演示数据可重新初始化。
5. 禁用模型密钥或断网，确认 AI 功能降级为带“演示缓存”标识的确定性结果。
6. 需要验证部署深链接时运行 `npm start`，直接打开 `/app/course` 与 `/m/course`。
